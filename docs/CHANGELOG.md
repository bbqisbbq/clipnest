# 变更史

> 一版一段，只记**用户能感知的变化**与**数据层面的破坏性改动**。实现细节与踩坑记录在
> [HISTORY.md](HISTORY.md)，当前架构在 [ARCHITECTURE.md](ARCHITECTURE.md)。
> 每版的发布说明（含截图与逐条解释）另存 `release-notes-v<版本>.md`，只有最新的几份需要留。

## 2.9.1（2026-11-20）

- 修：**「记一笔」和快速粘贴窗不跟随主题切换** —— 两个弹窗都在应用启动时读一次
  `localStorage` 里记的配色，之后就再也不看了。所以应用跑着的时候在设置页换主题（或换深浅），
  主窗口当场变色，两个弹窗却要重启才跟上。现在它们和主窗口共用同一套
  `applySettingsTheme`（预设 / 深浅 / 自定义 CSS / 原生窗口边框），并订阅 `settings:changed`。
- 说明：**「弹窗透明」在浅色主题下看着像没生效** —— 其实生效了，是白叠白。实测
  （`scratch/e2e-capture-transparency.ps1`，按像素量）：浅色 + 蓝色背景，卡片
  `250,249,245 → 214,227,244`（明显带上背后的蓝）；浅色 + 白色背景，`250,249,245 → 243,242,240`
  （7 级差距，肉眼看不出）。深色 + 白色背景是 `14,16,21 → 54,55,59`。设置页的说明里写了这一点。

## 2.9.0（2026-11-20）

- 新：**「记一笔」浮窗不再是浮在桌面上的一块方砖** —— 窗口本身改成真透明，10px 圆角外面
  直接透出桌面（和快速粘贴窗同一套做法）。
- 新：**设置 → 交互与启动 →「记一笔」弹窗透明**（关 / 15% / 30% / 50%，默认关）。
  开了之后卡片底色变小半透明，能看见背后的窗口。默认关：卡片完全不透明，只是四角透。
- 说明：这里给的是**真透明**不是毛玻璃（WebView2 糊不了桌面背景）。半透明卡片必须让后端
  先给窗口开一层 DWM backdrop，否则 WebView2 会把半透明像素合到黑底上 —— 卡片会比实心还暗
  （实测 rgb(13,14,19) vs 实心 rgb(14,16,21)）。老系统上开不起 backdrop 时前端自动退回不透明。

## 2.8.3（2026-11-20）

**这一版把"说了但实际不工作"的功能修成真的**，外加一轮存储/同步的欠账清理。

- 修：**私有格式（Excel 区间、颜色、音频…）复制回来永远是"原始数据已不可用"** —— 采集时字节从没落库；
  现在真的存了，也能原样粘回，且两个格式名相同的不同数据不再被并成一条。
- 修：**同步包取的是最旧的 500 条**（少写了一个 `Tail`），超过 500 条的库，最近复制的东西永远同步不出去。
- 修：两台机器各复制过同一段文字，同步后会**长出重复卡片**（同 hash 不同 id 被插成两条）。
- 修：删掉内置「置顶」筛选器后无法恢复（`RestoreFilters` 只有一行注释、没有实现）——设置页
  「筛选器」区现在有「恢复内置筛选器」。
- 修：文件条目的「N 项已失效」前端从来没渲染过（那个 3 分钟一次的巡检等于空转）——卡片现在会写出来。
- 修：标题栏「记录中」暂停之后按钮被自己禁用，点不动。
- 修：删条目不清附件（`entry_blobs` 行与 `entry_files/` 文件永久残留，"数据占用"只增不减）——现在回收。
- 修：清空历史逐条删除（上千次 autocommit）→ 单事务；条目写入与 FTS 索引同事务（索引失败不再留下搜不到的条目）；
  删条目先删后写墓碑；同步合并同内容复用本地 id。
- 修：`Shutdown` 不等后台循环就关库（会刷 `database is closed`）→ 现在取消在途请求并等收尾。
- 修：采集关闭时回填富文本会**先把剪贴板清空再失败**（`WriteHTMLToClipboard` 漏了 `initFormats`）。
- 修：片段的执行类型（命令/程序/密码/富文本）以前直接写进 `entries.kind`，污染类型筛选且标题存不下来 ——
  独立成 `entries.snippet_kind` 一列，标题与使用次数也真的落库了。
- 修：卡片上的置顶/归档、详情里的片段设置以前**整行回写**（把别处刚改的字段、同步拉回来的对端修改一起盖掉）——
  改成字段级接口（`SetEntryPinned` / `SetEntryArchived` / `SetSnippetFields`）。
- 修：搜一个字查一次库 + 每张卡片每次都重新解析 Markdown；后台刷新会把已加载的更早几页整段丢掉；
  快速切筛选器时老响应能顶掉新结果（现在有请求序号与合并策略）。
- 修：详情页与确认弹窗同时抢 Esc（一次按键关掉弹窗又弹一个）；`Ctrl+F` 搜不到焦点；
  侧栏 `⋯` 菜单点别处关不掉；`todo` 图标渲染成图钉；快速粘贴窗数字直选会抢搜索词（搜 "2026" 直接粘第 2 条）。
- 新：**更新提示条**（设置页一直写着"会在窗口顶部提示"，此前从没画过）、**「记一笔」快捷键可配**、
  **缩写后缀可配**、**待办勾错可以撤销**、**待办空态按钮真会预填 `- [ ] `**、**草稿恢复时的提示**。
- 新：接了此前无人监听的 7 个后端事件（设置变更 / 同步状态 / 删除 / 粘贴失败 / 计数 …）。
- 工程：清掉 34 条死样式与若干半截代码，写死的色值改回 token 变量，文档按"还在生效/只是历史"重排。
