# 隐写输入（无输入框的快速备忘）

> 一句话：**屏幕上不多一个字，但你说的话会被记下来**——按 `Ctrl+Alt+N` 激活，随便写，
> `Ctrl+Enter` 才落成备忘。写 `@名称@` 就落进同名条目。

## 一、为什么是「透明输入窗」而不是「吞键」

最低成本的实现是装个键盘钩子、把按下的键吃掉、自己攒字符串。这条路有两个硬伤：

1. **中文废掉**。低级键盘钩子看到的是"按键"，喂给输入法之前就被吞了——IME 收不到键，
   就没有拼音、没有候选框、没有汉字，只剩英数符号。
2. **没有反馈就没有安全感**。打字全靠脑补，一个错字要事后去库里找。

所以这里反过来做：窗口**是有的**，只是全透明——`BackgroundTypeTransparent` + 文字/光标/选区
全部透明色。它是一个真正的 `<textarea>`，因此

- 输入法照常工作，候选框还在光标旁边（因为你确实在光标旁边打字）；
- 你敲什么它都收得到，`select` / 删除 / 方向键这类编辑行为也不用自己实现；
- 屏幕上什么都看不见。

代价是它会**抢走焦点**：原来那个应用的光标会停止闪烁，直到你退出。这是这个方案的边界。

## 二、语义

| 操作 | 结果 |
| --- | --- |
| 激活（`Ctrl+Alt+N` / 托盘「隐写输入」） | 光标旁出现一个看不见的输入窗，右下角亮起状态灯 |
| 直接输入 | 只进内存缓冲，屏幕上不出现任何字符 |
| `Ctrl+Enter` | 提交：写进目标条目 → 清空缓冲 → 模式继续 |
| `Enter` | 换行（正文可以多段） |
| `@名称@` | 本次（以及之后的）内容写进**标题为「名称」**的条目；不存在就新建 |
| `@-@` | 忘掉名称；之后每次提交都存成新的一条 |
| `Esc` / 再按一次热键 / 点了别的窗口 | 退出；缓冲非空则**先保存一次**（不丢字） |
| 状态灯 | `@目标@ · 12`（目标 + 当前缓冲字数）；没有目标时显示「新条目」 |

目标的"粘住"是刻意的：写一次 `@随记@`，后面就不必每次重复。粘住只活在**本次进程运行期间**，
重启 ClipNest 后回到"每次新建"。

## 三、代码分工

| 位置 | 职责 |
| --- | --- |
| `internal/clip/service_stealth.go` | 会话状态、`@名称@` 解析、提交与落库、开关窗口的时机 |
| `internal/clip/entry_store.go` | `FindEntryByTitle` / `AppendTextToEntry`；`title` 列（含老库补列迁移） |
| `internal/clip/picker_windows.go` | `WorkAreaBottomRight`（状态灯位置）、`MakeNonActivating`（`WS_EX_NOACTIVATE`） |
| `main.go` | 两个窗口（`?mode=stealth` / `?mode=stealthhud`）、全局热键、托盘入口 |
| `frontend/src/Stealth.tsx` | 透明 `<textarea>`：提交/退出/失焦保存、进度上报 |
| `frontend/src/StealthHud.tsx` | 角落状态灯（200ms 轮询 `StealthState`） |
| `frontend/src/styles/stealth.css` | 透明窗口的底色、隐形输入框、状态灯样式 |

写入走的是普通条目：`SaveEntry`（新建）或 `AppendTextToEntry`（追加，空行分隔）。
**必须整条读回来再存**，否则只带 id 的局部 Entry 会把 tags / actions / 触发词洗掉——这条在
`AppendTextToEntry` 里有注释，`stealth_test.go` 里有对应的测试。

## 四、已知边界

- **抢焦点**：激活时原应用失焦（标题栏会变灰、光标停止闪烁），退出时自动还回去。
- **不会窗口化**：输入窗固定在激活时的工作区位置（光标处）；切到别的显示器/滚动了页面，
  输入法候选框仍跟着那个窗口，但你的视线可能已经离开。重新按一次热键即可。
- **不提权**：和剪贴板监听一样，ClipNest 是非提权进程；在管理员窗口里打字时热键本身不生效
  （全局热键是系统级的，能触发，但输入窗拿不到焦点）。
- **透明依赖合成**：窗口用 DirectComposition 透出桌面；如果某些显卡驱动把透明渲染成黑块，
  状态灯还会亮，但输入窗会显示成一块黑矩形——这种情况报日志里「stealth window: pos=…」那行。
- **不做富文本**：缓冲是纯文本，提交后按 Markdown 存（所以 `**加粗**`、`- 列表` 事后渲染正常）。

## 五、怎么验证

```powershell
go test ./internal/clip -run 'Stealth|Title|AppendText' -v   # 解析、粘住目标、追加不丢属性
go build -o bin\clipnest-dev.exe .                            # 内嵌前端产物
```

手测清单（每次改这块都过一遍）：

1. 记事本里把光标放到某行，`Ctrl+Alt+N` → 输一段中文（候选框应在光标旁）→ `Ctrl+Enter`
   → 打开管理窗口，内容出现在时间线里，且记事本里**没有**任何字。
2. 同一次激活里连写两条 → 库里是两条独立记录；写 `@随记@ 第一条`、再写 `第二条`
   → 两条都进了「随记」这篇，中间空一行。
3. `Esc` 退出 → 焦点回到原来的窗口，光标位置没变。
4. 激活后直接点别的窗口 → 缓冲自动保存，模式退出。
5. 走到屏幕最右/最下边缘再激活 → 输入窗被夹在工作区内，状态灯不遮挡任务栏。
