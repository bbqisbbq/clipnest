# 2026-11-19 界面舒适化（暖白 + 软圆角）

## 为什么做

用户反馈：主题不舒适——「字太小 / 灰字发虚 / 亮部刺眼 / 层次糊 / 空而飘 / 挤」。
诊断结论：不是「web 感」的问题，是**字号层级 + 灰阶对比 + 材质层次**三件事一起偏低。

量化证据（改前）：

| 项 | 改前 | 问题 |
| --- | --- | --- |
| 正文 | 13px | 中文在这一档偏小 |
| 元信息 / 标签 | 11 / 10px | 中文 10–11px 笔画糊 |
| `--text-3`（浅色） | `#7c8598` | 白底 3.7:1，低于 AA 4.5 |
| `--text-3`（深色） | `#6e7686` | 近黑底 4.31:1，卡在边缘 |
| 亮部端点 | `#ffffff` / `#0a0b0f` | 两端都顶到极值，缺缓冲 |
| 面板层次 | 只有 1px hairline | 元素"浮"在面上 |
| 卡片行距 | 42px 行高配 11px 字 | 空而散 |

## 做了什么

### 1. 配色：暖白纸感（用户从 A/B/C 三版里选 A）

`lib/themes.ts` 的 `default-light` 换成米白 + 赭石：

- `--bg #ecebe6` / `--surface #faf9f5` / `--surface-2 #f3f1ea`
- `--accent #9a5a34`（赭石），`--text-3 #6f675b`（对比 5.3:1）
- 原「纯白面板 + 靛蓝」没有删，另存为 `pure-light`（显示名「亮白」），避免替用户砍选择。

`theme-light.css`：六种条目类型色（`--k-*`）从蓝/青/橙/紫/粉压到低饱和暖灰调，同屏不再五彩。

### 2. 形状：圆角与抬升（用户选 B）

- `--r-sm/md/lg/xl` 6/8/10/14 → **7/10/14/16**
- 新增 `--elev-card`：浅色是 `0 1px 3px + 0 14px 30px -24px` 的极淡扩散阴影，深色是
  `inset 0 1px 0 rgba(255,255,255,.045)` 顶部高光。卡片与输入框都用它，元素"落到"面上。
- `--read-w` 760 → **700**（中文行长 30–35 字）。

### 3. 排版与密度

- `body` 13 → **14px / 1.45**；`.memo-body` **14px / 1.72**；h1–h3 15px。
- 全局小字上移一档：11 → 12、10.5 → 11.5、10 → 11（`styles/*.css` 全量）。
- 侧栏标签去掉 uppercase 与 `.09em` 字距（中文小号大写的糊感来源），12px 正常字重。
- 侧栏项 12 → 13px，padding 7 → 6px（字变大、留白收回来，密度不被稀释）。
- 卡片 padding 14/16 → 13/16、间距 12 → 10，同上。
- `--on-accent` 新 token：实心强调色块上压什么字。深色预设（强调色偏亮）用深字，浅色用白字。
  深色 `#7d8cff` 上压白字只有 2:1，是个会翻车的对比，必须按预设区分。

### 4. 去"营销页"痕迹

- 主按钮：`linear-gradient(160deg,#6478ff,#8b62f3)` + 彩色投影 → 实心 `--accent` + 顶部 1px 内高光。
- 标题栏 logo 方块：渐变 + 光晕 → 实心强调色。
- 状态胶囊 / 自动标签：`border-radius: 999px` → `var(--r-sm)` / 5px。
- 写死的靛蓝 tint（`rgba(125,140,255,x)`、`#e3e8ff`、`#b9c5ff`、`#c3caff`、`#d5dbe8`…）全部改成
  `var(--accent-tint)` / `var(--accent-line)` / `var(--on-accent)` / `var(--text)`，
  否则换配色时会留一套上一版颜色。
