# ClipNest 2.7.0

这一版是「修坏掉的东西 + 把几处一直该做没做的工程改动做掉」。无破坏性变更，装完直接覆盖。

## 修好的问题

**片段（缩写展开）**
- 「设为片段」之后缩写不生效，得重启或动一下设置才行 —— 触发器索引只在内存里，之前只有保存片段/保存设置/启动会重建。现在任何可能改变缩写集合的写入（提升、取消、详情里改缩写、归档、删条目）都会重建。
- 富文本 / 链接 / 文件引用 / 私有格式的片段打缩写**什么都不出**（日志里是 `expand: "..." produced no text`）—— 条目 kind 被直接强转成片段 kind，`rich`/`link`/`files` 落进 `Render` 的 default 分支返回空串。现在做了映射。

**界面**
- 时间线的「今天」日期条压住上一张卡片的元信息（sticky 用了 `linear-gradient(…, transparent)`，下沿 32% 透明）。
- 时间线滚动时日期条上方有一条窄缝，卡片从缝里滑过去。
- 输入区工具栏图标贴着输入框边框（原来是 3px，现在是 12px，且与正文对齐）。
- 快速粘贴弹窗四角有四个小黑点（窗口不透明 + 卡片圆角 → 角落露出窗口底色）。窗口现在真透明。
- 日历：今天与选中互相打架（19 号同时是两者时只剩一个白点）、星期表头 9px 糊成一团、热度点落点偏右下、格子是个扁矩形。

**同步**
- 同步链路的四个真 bug：`RefreshEntryFiles` 污染 `updated_at` 导致指纹漂移、同步包 500 条截断无提示、`syncOnce` 的 defer-in-loop、重复的更新检查循环。

## 新增

- **「记一笔」浮层可拖动、可改大小**，尺寸记在本机（不同步到其他设备），位置仍跟着光标走。
- **详情页恢复片段模板变量**：日期 / 日期（长）/ 时间 / 日期时间 / 剪贴板 / 光标位置，点一下插到光标处。
- **日历「今天」按钮**：切到别的月份后能一键回到当月。
- **快速粘贴弹窗跟随主题**（以前永远深色）。

## 工程

- 抽出 `internal/winplat`：Win32 输入注入从两份变一份（`INPUT` 结构体带编译期尺寸守门，`sizeof` 不对直接编译失败）。
- `main.go` 505 行拆成 `main.go`（启动顺序）/ `wire.go`（窗口与热键）/ `tray.go`（托盘），去掉 8 个互相捕获的闭包。
- 删除类接口 `bool → error`，前端终于能区分「不可删」和「已经没了」。
- Go 与前端死代码清理（约 970 行）、文档漂移校正 20+ 处。

## 安装

下载 `clipnest-2.7.0-amd64-setup.exe` 覆盖安装即可。设置、条目、同步配置都保留。

> 提示：如果你的「记一笔」窗口现在是 420×160（最小尺寸），那是在上一版拖到过最小并记住了 —— 拖回来一次就好。
