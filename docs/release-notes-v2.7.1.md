# ClipNest 2.7.1

这一版只有一件事：**自动更新开始强制校验安装包签名**（另外把日历的拥挤与拉窗口溢出修好了）。

## 自动更新强制验签

以前更新只核对两样东西：下载地址是不是 GitHub 的、字节数对不对。这两样都拦不住"包被替换"——
大小可以凑，地址也可能被劫持或仓库被改动。现在加了一道 **ed25519 签名**校验：

- 发布时用私钥给安装包签名，`<安装包>.sig` 和 `.exe` 一起上传；
- app 下载完先验签，**验不过就删文件、拒绝安装**，并在日志和界面上说明原因；
- 发布里没有 `.sig` 的，更新检查就直接报「发布缺少签名文件（.sig），已拒绝更新」——
  也就是说，**漏签名 = 这次发布没人能更新上来**，这是刻意的：宁可停在旧版本。

私钥在 `build\signing\ed25519.key`（不入库），公钥硬编码在程序里。签名/验签工具是
`scratch/signinstaller`，发布包装脚本是 `scripts\sign-release.ps1`，README 里有完整发布流程。

> ⚠️ 私钥丢了会怎样：现有版本只认这把公钥，新私钥签的包它们都不认。真丢了得先发一版
> 「同时信任新旧两把公钥」的过渡版本，再换根。所以请把 `build\signing\ed25519.key` 备份好。

## 顺带修的

- **日历格子不再挤、也不再随窗口膨胀**：上一版把格子做成正方形（`aspect-ratio: 1`），
  结果侧栏 220px 时格子只有 18–24px、窗口拉宽到 420px 时格子长到 44px 把侧栏撑爆。
  现在行高固定 28px、间距 4px、整块卡片封顶 276px，任何宽度下都不变形。

## 安装

覆盖安装即可，设置与条目都保留。装完之后一次更新检查就能看到这个版本已经带签名。
