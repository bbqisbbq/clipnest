# ClipNest 2.8.2

> 这一版是从"用起来不对"的地方里挑出来的四件事：**复制完不刷新**、**托盘菜单太长**、
> **草稿在极端时机丢字**、**另一台机器同步不过来时看不出为什么**；顺手做了一轮主题配色校准。
> 覆盖安装即可，设置与条目都保留。

## 1. 复制完，条目立刻出现在列表里

以前复制了东西，得**切一下页面**（或者换个筛选器）才能看见新条目。

根因不是采集，而是显示：主窗口从来没有监听后端发来的 `clip:new` / `clip:updated`
（唯一的听众是快速粘贴弹窗），时间线只在挂载和换筛选器时加载一次。

现在窗口订阅了采集事件：复制、同步拉到别的设备写的内容、清空历史，都会立刻反映到
时间线和侧栏计数上；**如果你正往上翻历史，列表不会把你拽回底部**（只有本来就在底部时才跟着滚）。
待办页同理，新条目里带的 `- [ ]` 会直接出现在待办列表。

## 2. 托盘菜单缩到 6 项

| 保留 | 删掉（以及为什么） |
| --- | --- |
| 快速粘贴（光标处） | 显示管理窗口 —— 左键点托盘图标就是它 |
| 暂停 / 继续收集 | 记一笔（剪贴板内容）—— 剪贴板本来就被自动采集，存出来是重复副本，且没有任何反馈 |
| 开机自动启动 | 清空未收藏的历史 —— 一键毁数据、没有确认（设置页里有带确认的那个） |
| 打开设置 | 检查更新… —— 设置页里有，而且原先点了只是把窗口翻出来 |
| 打开数据目录 | 更多 ▸ —— 里面只有两项，直接平铺 |
| 退出 ClipNest | |

顺手修了一个真 bug：托盘的「打开设置」以前**点了不会跳**（后端发了导航事件，前端没人听），
现在真的会打开设置页。托盘 tooltip 补了「左键打开」。

## 3. 草稿：换了落盘方式，敲完就关也不丢

以前防抖在浏览器里：停手 0.4 秒才写库，而那 0.4 秒里进程被强杀就丢字；更常见的是
**点 × 把窗口收进托盘**——原生隐藏不一定会让页面收到 `visibilitychange`，最后几个字就悬着。

现在：

- 输入的字**立刻**送进主进程内存（每键一次 IPC，很便宜），SQLite 写按 0.4 秒合并；
- **点 × 收起窗口、切到别的窗口、退出应用**都会立刻补写一次（后端在窗口隐藏钩子里发信号）；
- 正常退出还会在关库前再兜底写一次。

端到端验证：敲完**立刻**点 ×、300ms 后强杀进程，重启后草稿完整回到输入框。
唯一剩下的极限是「强杀/断电正好卡在最后一次按键后的 0.4 秒内」。

## 4. 同步："没同步过来"现在会直接说原因

远端只有一个包时，本机拉取永远是 0 条——以前这也显示成"拉取 0 条新增 / 0 条更新"，
看起来像一切正常。现在：

- 同步结果行会写明「**远端只有本机一个包：其他设备还没上传过**」；
- 「测试连接」同样给出这句话，并告诉你下一步做什么；
- 设置页设备表下方补了一条说明（另一台机器要开同步、填**同一个目录**、点一次「立即同步」）。

`docs/SYNC.md` 里加了一节「另一台机器没同步过来怎么查」：地址是否同一个目录、
坚果云必须用**应用专用密码**、看那台的 `clipnest.log`、以及两台机器 `deviceId` 是否撞了
（撞了说明其中一台是复制整份数据目录装出来的，会互相抢写同一个包）。

## 5. 主题与可访问性

- **弱化文字对比度**：五个预设里 `--text-3` 在侧栏行/chip 的底色（`--surface-3`）上
  最低只有 **3.03:1**，11~12px 的小字会糊。全部校准到 ≥4.5:1（最低 4.55）。
  强调色、成功/警告色在同样的底色上也一并补到 4.5 以上。
- **条目类型的浅底色**以前是写死的深色主题那套 rgba，切到暖白/纸感时底色和字色是两个色相；
  现在由 `color-mix()` 从当前类型色现算，换主题不会串色。
- **修了一个只在特定组合下出现的 bug**：浅色专属样式原来按「用户/系统选的深浅」命中，
  而不是「当前预设自己的深浅」——所以**选「纸感」+ 系统深色**时，深色那套类型色会压到米白底上。
- 窗口左上角 logo 方块上的字改用 `--on-accent`（深色预设的亮强调色配白字只有 2.7:1）。
- 新增全局键盘焦点圈（`:focus-visible`）与 `prefers-reduced-motion` 支持。

## 6. 一起带上的小修

- 侧栏不会再出现「待办」和某个筛选器**同时高亮**。

## 安装

覆盖安装即可（设置、条目、草稿都保留）。安装包与本版的签名文件一起发布，
「设置 → 更新」里能直接看到并升级。
