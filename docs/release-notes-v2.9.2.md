# ClipNest 2.9.2

> 「记一笔」弹窗透明的调节方式改了：**四个按钮 → 一根滑块，0–100%**。覆盖安装即可。

## 一、滑块代替按钮

设置 → 交互与启动 → **「记一笔」弹窗透明**

- 以前是 关 / 15% / 30% / 50% 四个按钮，想调细一点调不了；
- 现在是一根滑块，**0–100%，每 5% 一档**，右边实时显示当前值（0 显示「关」）。

## 二、拉到 100% 是什么效果

**100% = 卡片自己不再画任何底色**，只剩文字和一圈细边。这时候露出来的是窗口背后那层
DWM 磨砂玻璃（Acrylic），不是背后窗口的原样像素。实测（按像素量）：

| 档位 | 背后是白窗 | 背后是蓝色窗口 |
| --- | --- | --- |
| 0%（实心） | `14,16,21` | `14,16,21` |
| 30% | `54,55,59` | `16,41,77` |
| 100% | `146,146,146`（玻璃灰雾） | `21,102,208`（≈ 背后的蓝） |

所以：

- 背后是**彩色/深色**内容时，100% 基本等于"文字浮在背景上"，很通透；
- 背后是**白文档**时，100% 是一层浅灰色玻璃（`146`），文字还看得清 —— 这其实比 30% 更适合
  白底环境，因为卡片变成了一层均匀的雾面而不是白叠白。

要说清楚一点：**"文字直接浮在桌面上、卡片区域像素完全等于桌面"这一档做不到** —— WebView2 那层
表面不透明，页面 alpha=0 的位置只能露出 Acrylic。这是这套技术栈的边界，不是开关问题。

## 三、验证

`scratch/e2e-capture-transparency.ps1` 现在支持 `-Mid <百分比>`（默认 30）。三档都按像素量过：

```
-Preset default-dark -Backdrop '#ffffff'             # 0% vs 30%
-Preset default-dark -Backdrop '#ffffff' -Mid 100    # 0% vs 100%
-Preset default-light -Backdrop '#1e6fd9'            # 浅色主题必须用彩色背景才量得出来
```

`go test ./internal/...`、`npx tsc --noEmit`、`npx vite build` 全绿；滑块的视觉效果见
`scratch/shot-settings-slider.ps1` 的截图。
