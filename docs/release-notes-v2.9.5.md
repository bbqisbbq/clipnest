# ClipNest 2.9.5

一句话：**条目有标题了，图片里的字能搜到了。**

## 标题

正文里第一个 `# 一级标题` 会自动变成条目标题（卡片顶部那一行），详情页右栏可以手写覆盖。

- `自动`：正文改了，标题跟着变
- `手写`：正文再改也不动它
- `空`：正文里没有一级标题，卡片不多那一行

派生规则跟渲染器对齐：`#标签` 不算标题（`#` 后没有空格），代码块里的 `# xxx` 不算，二级及以下不算，收尾井号与行内强调/链接语法会被清掉。

## 图片文字识别（OCR）

复制一张截图，图里的文字会自动识别并进搜索索引 —— 之后用图里的词就能搜到它。

- 卡片上出现 `OCR 169 字` 徽章；详情页右栏能看全文、一键「复制识别文字」
- **右键卡片**就能「识别图里的文字 / 重新识别 / 复制识别文字」
- 全部在本地完成，不联网；识别结果跟着条目走（同步到其他设备，省得重复算）
- 两个字的关键词也搜得到（短词走 LIKE 分支，连带 `ocr_text`）

默认用 **Windows 自带的 OCR 引擎**（零依赖、每张约 0.5 秒）。想要更高精度可以切到
**PP-OCRv5 + onnxruntime**：设置 →「图片文字识别」→「打开资源目录」，把
`onnxruntime.dll`、`det.onnx`、`rec.onnx`、`ppocr_keys.txt` 放进去，点「重新检查」。

## 卡片右键菜单

复制内容 / 识别图里的文字 / 复制识别文字 / 打开详情 / 置顶 / 加入粘贴列表 / 设为片段 / 归档 / 删除。

点外面、按 Esc、窗口失焦都关；贴到屏幕右边或底边会自动翻转；↑↓ 选、Enter 执行；删除永远是最后一项且标红。

## 升级说明

- 老库自动迁移：`entries` 多两列（`title_source` / `ocr_text` / `ocr_state`），不需要手动做什么
- 开机后的空闲时间会**后台补扫历史图片**（一次 200 条），跑完就会有 OCR 徽章
- 自动同步间隔仍是你在设置里那个值（新装默认 120 分钟）
