# ClipNest 2.12.2

两个小改动，都在「记一笔」那个弹窗上。

## 修：弹窗外面那圈黑边没了

之前弹窗四周有一圈 1px 的灰边（黑底上特别明显）。来源不是页面的边框，是 Windows 的 DWM
给每个窗口画的那条边框线——暗色主题下是 rgb(47,47,47)。它沿着**方形窗口轮廓**走，而弹窗是
圆角卡片 + 透明窗口，于是这条线正好压在本该透出去的边上。

现在弹窗不再画 DWM 边框（主窗还留着，它是方形带边框的）。

## 改：去掉毛玻璃

「弹窗透明」这项之前是靠 Windows 的 Acrylic 合成层实现的——也就是磨砂玻璃。你把它拉到
100% 时，卡片完全透掉，看到的其实是那层被糊掉的桌面。

2.12.2 起默认关掉合成层：弹窗是一块**实心卡片 + 真圆角**（四个角仍然透出桌面），
没有任何磨砂。

**为什么不是"透明但不磨砂"**：在 WebView2 里做不到。半透明的像素如果没有合成层，
会被合到一层黑底上（实测比实心还暗一点）。我试过两条经典的"只混合不模糊"的路子
——`DwmEnableBlurBehindWindow` 加空模糊区域、以及窗口分层 alpha——都用像素量过，
卡片一动不动。所以这一项在设置页标成「暂不可用」；真·半透明要等这个弹窗改写成原生窗口。

想要回旧的毛玻璃效果：设环境变量 `CLIPNEST_CAPTURE_ACRYLIC=1` 再启动。

## 升级

装 `clipnest-2.12.2-amd64-setup.exe`（右键以管理员身份运行）。数据与设置都在
`%APPDATA%\ClipNest`，不受影响。
