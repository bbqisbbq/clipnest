# ClipNest 2.12.3

## 毛玻璃回来了

2.12.2 我为了去掉磨砂把弹窗背后的合成层关了，结果「弹窗透明」直接失效（卡片退回实心）。
这版按你的要求把它加回来：透明 > 0 时背后重新开 Windows 的亚克力（Acrylic）合成层，
卡片半透明才会真的与背后的窗口混合——观感就是磨砂玻璃。设置页那一项恢复可用，说明里
也写清楚了这一点。

## 顺手把「黑边」真正修掉了

2.12.2 那版只是不再给弹窗设置边框颜色，但 **Windows 11 默认就会给每个窗口画一圈 1px 边框**
（暗色下是浅灰），所以透明度 0% 时那圈线其实还在。这版改成显式告诉 DWM「不要画边框」，
黑底上 0% 的卡片边缘现在是干净的：卡片颜色直接接上桌面，中间没有夹层灰线。

一点残留：透明度 > 0 时，亚克力材质自身会在最外沿留一道更亮的 1px 高光，那是这种材质的
固有特征，去不掉。想要完全没有边、又想要真透明，只能把这个弹窗改写成原生窗口（已实测可行，
还没做）。

## 升级

装 `clipnest-2.12.3-amd64-setup.exe`（右键以管理员身份运行）。数据与设置在
`%APPDATA%\ClipNest`，不受影响。
