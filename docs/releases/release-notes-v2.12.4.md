# ClipNest 2.12.4

## 一个小但会误导人的显示 bug

设置页「云同步」里的**上次同步时间一重启就失忆**：它以前只存在内存里，所以重启后那个位置
显示的是「从未同步」和 `1/01/01 08:05:43`（格式化的零时间）——即使几分钟前刚同步成功。

现在每次同步成功都会把摘要（时间 / 拉取结果 / 本机包大小 / 设备数）写进库里，启动时读回，
面板终于不会"忘事"了。

顺带提醒：**排查「一台机器的内容同步不过去」时，先看同步开关有没有打开**——开关关着时
「立即同步」是灰的，同步循环直接空转，远端自然看不到这台机器的包。

## 升级

装 `clipnest-2.12.4-amd64-setup.exe`（右键以管理员身份运行），数据与设置不受影响。
