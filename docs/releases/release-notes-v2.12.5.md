# ClipNest 2.12.5

## 「记一笔」现在会跟着深浅主题变了

原因有点绕：这个弹窗的**半透明是靠 Windows 的亚克力（Acrylic）材质**实现的，而那层材质会按窗口的
`immersive-dark` 标志挑「浅色版」还是「深色版」。上一版为了去掉黑边，把弹窗的 DWM 设置全关了，
顺带把这枚标志也关了 —— 于是无论你选深色还是浅色，弹窗背面永远糊着一层**浅色**玻璃。

实测（把透明度拉到 100%，屏幕上看到的就是这层材质本身）：

| | 修复前 | 修复后 |
| --- | --- | --- |
| 浅色主题 | (153,151,155) | (167,163,161) |
| 深色主题 | (153,151,155) ← 一模一样 | (73,71,70) |

现在三个弹窗（快速粘贴 / 记一笔 / 截图）都会同步这枚标志，运行中切换主题也是即时生效的
（实测：暗色 (50,48,47) → 切到浅色 (244,246,249)）。弹窗被闲置销毁后重建，也会补上当前主题。

## 升级

装 `clipnest-2.12.5-amd64-setup.exe`（右键以管理员身份运行），数据与设置不受影响。
