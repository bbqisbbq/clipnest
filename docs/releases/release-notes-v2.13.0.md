# ClipNest 2.13.0

## 搜索现在能"按意思找"了

以前搜索只认**字面**。你记得复制过一段关于同步失败的东西，但记不住原话 —— 那就搜不到。

现在试一句：

> **云端传不上去**

它会找到你那条 **「坚果云 WebDAV 同步失败，检查服务器地址是否一字不差」**。
两句话一个词都不重。

这不是把关键词拆开模糊匹配，是真的**按意思**找。字面那一路还在（"我记得里面有个
`proxy_pass`"这种查询还得靠它），两路结果按名次融合排在一起。

## 为什么放进 ClipNest 而不是调云端

- **全在本机算**。不联网，不上传你的剪贴板。
- **够快**：单条编码 2.2 毫秒，1 万条历史全量扫一遍 4.8 毫秒。所以不需要向量数据库那种
  重型基础设施 —— 搜索框敲完就是结果。
- **够小**：模型 22.9MB（bge-small-zh-v1.5 的 INT8 版）。而且是可选下载，
  不装就用不了这个功能、但**搜索行为与以前一模一样**。

顺手记一个否掉的方案：更大的 bge-base（98MB / 768 维）召回反而更低（前五命中 64% vs 67%），
不值得 4 倍体积。这个任务的瓶颈不在模型容量。

## 要不要装

装：**设置 → 搜索 → 一键下载（23 MB）**。下载完会立刻把历史条目编一遍
（每条约 6 毫秒，一万条约一分钟，后台跑，能看见进度）。

不装完全没影响 —— 搜索框照旧，只是少一半能力。

设置里那一节还能看到「已索引 N 条」，以及一个开关：不想要语义搜索就关掉，
回到纯字面。

## 它不是万能的（实测数字）

39 条评测集，每条查询都刻意避开目标条目的用词：

| | |
|---|---|
| 这批查询字面能命中 | **0%**（以前一条都搜不到） |
| 向量前五命中 | 67% |
| 向量前十命中 | 77% |

也就是说：大概三分之二的"记不清原话"能一次找到，剩下那些还得往下列几条看看。
短查询撞上一堆长得很像的命令行条目时会挑错人 —— 这也是为什么字面那一路必须留着。

## 内存

模型会话不常驻：闲置五分钟自动释放（那 43MB 还给你），下次用到再加载（0.25 秒）。

## 升级

装 `clipnest-2.13.0-amd64-setup.exe`（右键以管理员身份运行），数据与设置不受影响。
装完想用语义搜索，再去设置里点一次下载即可。
