# ClipNest 2.13.2

## 修：搜索的条数越滚越多

搜索框里敲一句查询，右上角显示「560+ 条」，可库里一共才 82 条 —— 你截的那张图就是这个。

原因在翻页：搜完之后往上滑会触发"加载更早"，而搜索结果的排序（相关性）**没有时间游标**
可翻。我上一版为了省事把游标清掉了，结果每次"加载更早"都重新拿到**同一页 50 条**，
前端又是直接往前拼、不去重 —— 于是 50、100、150…… 一路涨到 560。

现在两处都改了：

- 后端不再清游标：相关性排序下带游标的请求一律明确返回空（= 没有更多了），
  列表上游那个「+」也会跟着消失；
- 前端改成按 id 去重的合并，后端万一重复给也不会越滚越长（兜底）。

所以语义搜索现在只给一页：滑到头就是"没有更多了"。这是相关性排序的固有取舍
（名次和"创建时间"不是一回事，没法用时间去翻页）。

## 升级

装 `clipnest-2.13.2-amd64-setup.exe`（右键以管理员身份运行）。模型资源不用重下。
