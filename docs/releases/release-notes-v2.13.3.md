# ClipNest 2.13.3

## 修：OCR 设置页报「引擎加载失败」

报错长这样：

> 引擎加载失败：onnxruntime 初始化失败: The onnxruntime has already been initialized

OCR 其实一点没坏。onnxruntime 的运行环境是**整个进程共用一份**、只能初始化一次，而
「图片文字识别」和「语义搜索」是两套独立的引擎，各自都去初始化了一次：

- 谁先跑，谁初始化成功；
- 后跑的那个拿到"已经初始化过了"这句话，把它当成了错误。

语义搜索在后台补扫历史条目时先跑起来，于是 OCR 就"报错"了。你重启一下，或者先触发 OCR
再搜索，顺序反过来就不会出现 —— 这也是它看起来时有时无的原因。

现在这件事收进了一个入口，两个引擎都走它；"已经初始化过了"只可能是自己人干的，
按成功处理。

## 升级

装 `clipnest-2.13.3-amd64-setup.exe`（右键以管理员身份运行）。模型与 OCR 资源都不用重下。
