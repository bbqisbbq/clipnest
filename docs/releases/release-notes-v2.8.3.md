# ClipNest 2.8.3

> 这一版是一次**功能审计**的结果：把"文档里写了、用起来却不工作"的地方修成真的，
> 顺手把存储与同步的生命周期欠账收干净。覆盖安装即可，设置与条目都保留（数据库只加了一列，自动迁移）。

## 一、修好的五个"说了但不工作"

**1. 私有格式复制回来永远是「原始数据已不可用」**
Excel 区间、颜色、音频这类格式，采集时其实拿到了字节，但**从没存进库** —— 正文里只剩格式名，
点「复制」自然取不回来。现在字节真的落库（大文件走 `entry_files/`），能原样粘回；
同一格式名的两份不同数据也不会再被内容哈希并成一条。

**2. 同步包取的是最旧的 500 条**
打包时少了一个"取最新"的标记，于是拿到的是**最旧**的 500 条。库超过 500 条之后，
你最近复制的东西永远同步不到另一台机器上。现在取最新的 500 条。

**3. 两台机器同步后长出重复卡片**
两端各自复制过同一段文字（内容哈希相同、条目 id 不同），合并时按远端 id 插入，
库里就多出一条一模一样的卡片 —— 而且之后每轮同步还可能再加一条。现在合并沿用本地 id。

**4. 删掉「置顶」筛选器后找不回来**
侧栏 `⋯` 里能删的内置项只有「置顶」，但还原用的 `RestoreFilters` 在代码里只剩一行注释。
设置 → 筛选器 现在有「恢复内置筛选器」按钮。

**5. 文件条目的「已失效」从没显示过**
后端每 3 分钟扫一遍"原文件还在不在"，前端一处都没读这个状态（等于空转）。现在卡片上会写
「2/3 项已失效」（悬停看具体路径）。

## 二、数据与资源不再累积坏账

- 删条目**不清附件**：`entry_blobs` 行与 `entry_files/` 里的文件永久残留，设置页的「数据占用」只增不减。
  现在删除时回收没人引用的附件（内容寻址，同一张图被多条引用时不会误删）。
- 条目写入与全文索引**不再分开提交**：索引失败只记一条日志，那条内容会永久搜不到。现在同一个事务，
  失败就整条回滚。
- 删除改为**先删后写墓碑**（反过来的话删除失败会对端已删、本机还在）；清空历史从"上千次逐条删"改成单事务。
- 退出时**等后台循环收尾**再关库（以前会刷 `database is closed`，极端时序下中断一次合并）。
- **采集关闭时回填富文本会清空你的剪贴板**：`WriteHTMLToClipboard` 漏了格式注册，先 `EmptyClipboard`
  再失败。现在先确认格式就绪再动剪贴板。

## 三、配置与编辑不再互相覆盖

- 卡片上的置顶/归档、详情里的片段设置，以前是**拿一份旧快照整行回写** —— 会把别处刚改的字段、
  甚至同步刚拉回来的对端修改一起盖掉。现在只改对应那几列。
- 片段的执行类型（命令 / 程序 / 密码 / 富文本）以前直接写进 `entries.kind`，污染类型筛选，标题也存不下来。
  现有独立字段，标题与使用次数也真的写库了（旧数据照原样认）。
- 设置自动保存：两次改动挨得很近时，第一笔会被后一笔用旧快照弹回去；现在排队执行，
  失败会真的重试（状态条不再空口承诺）。

## 四、用起来更顺的地方

- **发现新版本会在窗口顶部提示**（设置页一直这么写，但那个提示条以前不存在），可直接「下载并安装」。
- **「记一笔」快捷键可以改了**（设置 → 交互与启动），撞上别的软件时会明确报错而不是装作保存成功。
- **缩写后缀可以改了**（设置 → 片段与缩写）。
- **待办勾错了能撤销**（10 秒内），空态那个按钮现在真的会预填 `- [ ] ` 等你写第一条。
- **Ctrl+F 到搜索框**、卡片可以 Tab 进去（`Enter` 展开、`Ctrl+Enter` 进详情、`Delete` 删除）——
  这几条 README 里一直写着，代码里却没有。
- 搜索有了防抖，卡片不再每次输入都重新解析一遍 Markdown；后台刷新不再把你正在翻的更早几页整段抽走；
  快速切筛选器时也不会再显示上一屏的内容。
- 快速粘贴窗：数字直选只在没输入关键词时生效（以前搜 "2026" 会直接粘第 2 条）；
  上下移动时列表会跟着滚；粘贴失败会写出原因。
- 侧栏 `⋯` 菜单点别处或按 Esc 会关掉；`todo` 图标不再渲染成图钉；按一次 Esc 不会再"关掉弹窗又弹一个"。
