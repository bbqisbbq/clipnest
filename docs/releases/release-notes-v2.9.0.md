# ClipNest 2.9.0

> 这一版只有一个主题：**「记一笔」浮窗不再是浮在桌面上的一块方砖**。
> 覆盖安装即可，设置与条目都保留（没有数据库结构改动）。

## 一、浮窗改成真透明

以前「记一笔」（Ctrl+Shift+N）虽然画了 10px 圆角，但**窗口本身不透明**——圆角外面还垫着一层
窗口底色，浮在桌面上就是一个 620×220 的深色方块。

现在窗口本身是透明的（和快速粘贴窗同一套做法：`BackgroundType` + DirectComposition）：
**四个圆角外面直接透出桌面**，边是干净的切边，不是画出来的方块。

## 二、新增「弹窗透明」设置（默认关）

设置 → 交互与启动 → **「记一笔」弹窗透明**，四档：**关 / 15% / 30% / 50%**。

- **关**（默认）：卡片完全不透明，只是四角透出桌面 —— 这是最稳的观感，也是新的一版默认值。
- **15% / 30% / 50%**：卡片底色变成半透明，能看见背后的窗口、文档、浏览器。

调到 30% 左右在日常场景最舒服：身后的窗口还能辨认，字仍然清楚。50% 是上限——
再往上（尤其背后是白色文档时）文字对比度就守不住了，所以没给更大的档。

## 三、一个必须说清楚的技术边界

这次做的时候踩到一个 WebView2 的坑，值得写进发布说明：

**WebView2 只给"全透明"，不给"半透明"。** 页面里 alpha=0 的像素确实能让桌面透出来
（所以圆角能真透明），但 alpha=0.7 的卡片底色**不会**与桌面混合，而是被合到一层黑底上 ——
第一版量出来的卡片是 `rgb(13,14,19)`，比实心的 `rgb(14,16,21)` 还暗。

解法是给窗口垫一层 DWM backdrop（`DwmSetWindowAttribute(DWMWA_SYSTEMBACKDROP_TYPE = Acrylic)`），
半透明像素才与它混合 —— 同一张卡片立刻变成 `rgb(54,55,59)`，能看见背后的窗口边缘。

所以：

- 「弹窗透明」调成 0 时**会关掉**这层 backdrop（圆角才是干净切边，也不为看不见的效果付合成开销）；
- 老系统上如果 backdrop 开不起来，前端会**自动退回不透明卡片**，不会硬透成一块脏色块。
- 给的是**真透明，不是毛玻璃**：WebView2 糊不了桌面背景，`backdrop-filter` 只会得到一片黑。
  想要磨砂感得走 DWM 那层，那是另一个功能。

## 四、验证方式

不是靠截图印象：`scratch/e2e-capture-transparency.ps1` 在沙箱 `%APPDATA%` 里起一个实例，
背后摆一块白色文本框，用真热键弹出浮窗，然后**按像素量**圆角外侧与卡片里的颜色。

```
0%   : 圆角外侧=231,231,231  卡片=14,16,21      ← 四角是背后的窗口，卡片是实心 surface
30%  : 圆角外侧=231,231,231  卡片=54,55,59      ← 卡片与背后混合了，四角仍透
```
